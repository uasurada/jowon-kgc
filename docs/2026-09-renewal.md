# 2026년 9월 홈페이지 개편 기록

## 개편 목적

기존 홈페이지의 인공지능 생성형 랜딩페이지 느낌을 줄이고, 정관장 조원점이 실제로 운영되는 오프라인 매장이라는 사실을 방문자가 즉시 확인할 수 있도록 전면 개편했다. 디자인 자체보다 매장 신뢰도와 상담 전환을 우선했다.

- 지역 표기: 수원시 장안구

## 메인 페이지

메인 페이지는 실제 매장 사진을 중심으로 다시 구성했다.

- 첫 화면에 리모델링된 매장 전체 전경 사용
- KGC 공식 가맹점, 매장 위치, 영업시간, 전국 택배 정보 강조
- 개인 선물 상담과 기업·단체 주문 동선을 분리
- 제품 진열, 상담 카운터, 매장 입구 사진 배치
- 전화와 카카오톡 상담 버튼 강화
- 모바일 하단에 전화·카카오톡 빠른 상담 버튼 고정
- FAQ와 검색엔진용 FAQ 구조화 데이터 정리
- 네이버 지도 길찾기를 새 주소 기준으로 변경
- 과장된 광고 문구와 반복적인 카드 구성을 줄이고 확인 가능한 정보 중심으로 작성

주요 파일:

- `app/page.tsx`
- `app/globals.css`
- `app/layout.tsx`

## 개인 선물 상담 페이지

- 실제 제품 진열 사진을 사용한 상단 비주얼
- 선물 대상, 예산, 수량을 버튼으로 선택
- 성함, 연락처, 추가 요청사항 입력
- 개인정보 수집 동의 UI 개선
- 전화와 카카오톡 직접 상담 제공
- 실제 매장 주소와 결제·포장·배송 안내 표시
- 신청 완료 화면 개편

주요 파일: `app/personal/page.tsx`

헤더 로고는 `public/logos/jungkwanjang-wordmark-white-v2.png`를 사용한다. 흰색 헤더에 맞춰 원본의 흰 배경을 유지하고 Next.js 이미지 변환을 거치지 않도록 `unoptimized`로 표시한다. 투명 배경으로 만든 시험 파일은 실제 페이지에서 사용하지 않는다.

매장 사진은 현재 구성만으로 실제 매장임을 충분히 전달한다. 유사한 진열 사진을 자동 슬라이드나 대형 갤러리로 추가하면 페이지가 길어지고 상담 행동이 분산될 수 있어 적용하지 않았다. 향후 사진을 추가한다면 일반 전경보다 실제 상담 모습 또는 선물 포장·배송 준비 사진이 구매 전환에 더 유용하다.

## 유지보수 참고

- 로컬 개발: `npm run dev`
- 프로덕션 검증: `npm run build`
- Vercel CLI의 로컬 저장 토큰은 2026년 9월 배포 당시 만료된 상태였다. 기존 GitHub–Vercel 연동을 통한 자동 배포는 정상 작동했다.
- 개발 서버와 `next build`를 동시에 실행하면 `.next` 캐시가 섞여 이전 이미지나 CSS가 표시될 수 있다. 이런 경우 개발 서버를 완전히 종료한 뒤 다시 실행한다.
- `img` 폴더의 사용하지 않는 사진과 문제 확인용 캡처는 운영 배포에 포함하지 않는다.
